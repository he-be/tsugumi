マークダウン（Markdown）での画像の埋め込みとリンクの書き方を解説します。

一番の違いは、**画像の前に「`!`（エクスクラメーションマーク）」をつけるかどうか**です。

---

### 1. 画像の埋め込み方
画像の構文は、リンクの構文に `!` を最初につけるだけです。

#### 基本構文
```markdown
![代替テキスト](画像のURL または パス)
```

* **代替テキスト**: 画像が表示されない時に表示される説明文です（SEOやアクセシビリティのために書くことが推奨されます）。
* **画像のURL/パス**: インターネット上のURL、またはPC内のファイルパスを指定します。

#### 具体例

**① Web上の画像を表示する場合**
```markdown
![ロゴ画像](https://example.com/logo.png)
```
> ![ロゴ画像](https://www.google.com/images/branding/googlelogo/2x/googlelogo_color_92x30dp.png) *(表示イメージ)*

**② ローカル（自分のPC内）の画像を表示する場合**
```markdown
![私の写真](./images/my-photo.jpg)
```

---

### 2. リンクの書き方
リンクの構文は、テキストをクリックすると指定したURLへ飛ぶようにするものです。

#### 基本構文
```markdown
[表示テキスト](URL)
```

#### 具体例

**① Webサイトへのリンク**
```markdown
[Googleに行きます](https://www.google.com)
```
> [Googleに行きます](https://www.google.com) *(表示イメージ)*

**② URLをそのまま書く（自動リンク）**
URLをそのまま書くだけでも、多くの環境では自動的にクリック可能なリンクになります。
```markdown
<https://www.google.com>
```
> <https://www.google.com> *(表示イメージ)*

---

### まとめ比較表

| 内容 | 書き方のルール | 実装例 |
| :--- | :--- | :--- |
| **画像** | `![説明](URL)` | `![猫](https://example.com/cat.jpg)` |
| **リンク** | `[テキスト](URL)` | `[ここをクリック](https://example.com)` |

**覚え方のコツ：**
「**「！」がついたら画像（Image）、「！」がなかったらリンク（Link）**」と覚えると間違いありません。
