HTML（HyperText Markup Language）は、ウェブページを作るための「骨組み」を作る言語です。

HTMLは、テキストを「タグ」と呼ばれる記号（ `< >` ）で囲むことで、「ここは見出しです」「ここは段落です」とコンピュータに指示を出していきます。

以下にその基本構造を分かりやすく解説します。

---

### 1. HTMLの基本構造（イメージ）

HTMLは、**「入れ子構造（親子関係）」**になっています。大きな箱の中に、小さな箱が入っているようなイメージです。

```text
<!DOCTYPE html>         <!-- ① 文書型宣言（これはHTML5ですよ、という宣言） -->
<html lang="ja">         <!-- ② HTML全体の開始（ここからHTMLの始まり） -->
  <head>                 <!-- ③ head：ページの「設定」を書く場所（画面には見えない） -->
    <meta charset="UTF-8"> <!-- 文字化けを防ぐための設定 -->
    <title>ページの題名</title> <!-- ブラウザのタブに表示される名前 -->
  </head>
  <body>                 <!-- ④ body：ページの「中身」を書く場所（画面に見える部分） -->
    <h1>見出し</h1>
    <p>文章の内容</p>
  </body>
</html>            <!-- HTML全体の終了 -->
```

---

### 2. 各要素の詳しい説明

1.  **`<!DOCTYPE html>`**
    *   「このファイルは最新のHTML（HTML5）で書かれています」ということをブラウザに伝えるための決まり文句です。一番上に必ず書きます。
2.  **`<html>`**
    *   すべての要素を包む「ルート要素」です。`lang="ja"` と書くことで「このページは日本語で書かれています」と指定できます。
3.  **`<head>`（ヘッド）**
    *   **「ページの情報」**を書く場所です。
    *   ここにある内容は、**実際のブラウザの画面（白い部分）には表示されません**。
    *   代わりに、「文字コードの設定（文字化け防止）」「ページのタイトル」「CSS（デザイン）の読み込み」など、ページを正しく動かすための重要な情報を入れます。
4.  **`<body>`（ボディ）**
    *   **「実際に画面に表示される中身」**を書く場所です。
    *   ここにテキスト、画像、リンク、ボタンなどを書いていくことで、私たちが普段見ているウェブサイトの見た目が作られます。

---

### 3. 簡単なHTMLの例

以下のコードをコピーして、メモ帳などのテキストエディタに貼り付け、ファイル名を `index.html` として保存してみてください。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>はじめてのウェブページ</title>
</head>
<body>

    <h1>こんにちは、HTMLの世界へ！</h1>
    <p>これはHTMLの基本構造を学ぶためのサンプルページです。</p>

    <h2>学習中のこと</h2>
    <ul>
        <li>HTMLのタグの使い方</li>
        <li>文章の書き方</li>
        <li>リンクの貼り方</li>
    </ul>

    <a href="https://www.google.com">Googleへのリンク</a>

</body>
</html>
```

### この例で使っているタグの解説
*   **`<h1>` 〜 `<h2>`**: 見出し（Heading）。数字が大きいほど小見出しになります。
*   **`<p>`**: 段落（Paragraph）。文章を書くときに使います。
*   **`<ul>`**: リスト（Unordered List）の開始。箇条書きの枠組みです。
*   **`<li>`**: リストの項目（
