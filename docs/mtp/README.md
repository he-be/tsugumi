## この計画の運用ルール

`PLAN_VISION.md` が 1,728 行になり、途中から誰も通読できなくなった反省で分けている。

- **1 文書 = 1 論点。**目安 200 行以内。超えたら分ける。
- **進捗は文書を増やして書く。**既存文書の先頭に `0-A` `0-B` … と積んでいく形は取らない。
  M0 の結果は `10-M0-RESULTS.md`、M1 は `11-M1-RESULTS.md` というように
  **段ごとに新しいファイル**を作り、この索引に 1 行足す。
- **設計文書 (01〜05) は書き換える。**結果が出て前提が変わったら追記ではなく本文を直す。
  「読むべき最新の設計」が常に 1 か所にあるようにする。訂正の履歴は git log が持つ。
- 受入結果は最後に `RESULTS_MTP.md` (リポジトリ直下、PLAN §6 準拠) にまとめる。
  `RESULTS_QAT.md` / `RESULTS_VISION.md` と同じ場所・同じ体裁にする。
