# 38. register の再現 — 運用点 (temp 1.0) で 3 反復し、軸を `2^H` に置き換える

測定: 2026-08-20 06:24〜06:34、M3 Pro 18GB / macOS 15.7.5 / commit `b7c86ab`。
`Sources/` は無改変。18 run すべて rc=0、一次資料は `bench/mtp38/`。

**目的は 1 つだけ。**[36](36-M9-A-CD-LEDGER.md) §11/§12 の register の主張は
**各セル 1 run・単一画像・temp 0・クールダウンなし**で立っていた。

N1〜N6 はその上に乗っている。**運用点で 3 反復し、生死を決める。**

36 §6 測定 8 との違いは 4 点のみ。他は同一 (32 スロット / bs=0 / thinking off /
192 tok / 画像 280 tok / `--messages-file` だけを振る)。

## 2. 三つの判定 (**実測**)

1. **最良と最悪の差は運用点でも残る。**hit 差 **12.37 pt ± 1.41**、
   速度比 **−21.4% ± 3.5%** (Welch、95%)。
   **36 の n=1 の主張 (12.2 pt / −21.9%) がほぼそのまま再現した。**
2. **熱ドリフトは +2.28%** (先頭 23.83 → 末尾 24.38 t/s、同一条件)。
   **符号は「速くなる」側**でスロットリングではない。hit は 93.2% → 93.2% で不変。
   効果 (21%) の 1/10 なので**セル間の差は読んでよい**。
3. **温度を運用点に上げると全セルが一様に 3〜5% 遅い** (−0.77〜−1.29 t/s)。
   一様なので register の結論には効かない。

## 3. 軸は `register` ではなく `2^H` である (**実測** + **導出**)

トレース 4 本 (計時とは別枠。トレースは計時を乱す)。
**36 で欠けていた `ja_bullets` と `en_prose` の 2 本がここで埋まった** (36 §7-22)。

| セル | `2^H` (層あたり実効エキスパート数) | hit% | tok/s |
| --- | ---: | ---: | ---: |
| ja_prose | 22.8 (36 の temp 0: 23.5) | 93.30 | 24.01 |
| ja_bullets | **28.6** (36 では未測定) | 90.27 | 22.69 |
| en_prose | **33.4** (36 では未測定) | 87.23 | 21.92 |
| en_bullets | 41.8 (36 の temp 0: 41.8) | 80.93 | 18.87 |

```
hit%  = 108.67 − 0.6553 × 2^H     R² = 0.9926   残差 ±0.44 pt
tok/s =  30.34 − 0.2674 × 2^H     R² = 0.9718   残差 ±0.52
```

**⇒ 4 セルが 1 本の直線に乗る。`register` (言語 × 書式) は `2^H` の代理ラベルに
すぎない。評価に必要なのはカテゴリ軸ではなく連続量 1 個である。**

## 4. 36 に対する訂正 2 件

1. **§12f の「32 スロットをまたぐ」という閾値の物語は支持されない** (**実測**)。
   4 点は 32 の前後にまたがるが、hit の低下は**滑らかで knee が無い**
   (1 単位あたり −0.522 → −0.633 → −0.750 pt と緩やかに加速するだけ)。
   「32 スロットは日本語散文がたまたま収まる数」は
   **「hit は `2^H` の連続な減少関数」**に置き換わる。
2. **§11/§12 は「未確認」から「実測」に戻してよい** — ただし
   **主張は `2^H` の言葉で書き直すこと**。register という言い方のまま残すと、
   カテゴリが 4 つあるかのように読めてしまう。

## 5. 限界 (**未確認**)

1. **本書は再現できない。**使った画像 `sample_imgs/IMG_2113.JPG` は測定後に
   ワークツリーから削除された (画像はリポジトリ外に移した。§6)。

4. **反復 3 は 4 セルの比較には足りるが、1% の差を分ける力は無い** (36 §17 と同じ)。

## 7. 再現手順

```bash
# 18 run / 約 10 分 / GPU プロセスは常に 1 個 / 20 秒クールダウン
# 4 セル × 3 反復 + 暖機 1 + ドリフト検定 1 + トレース 4
#   ja_prose   = bench/mtp_goal_prompt.json
#   ja_bullets = bench/mtp_register_ja_bullets.json
#   en_prose   = bench/mtp_register_en_prose.json
#   en_bullets = bench/mtp_register_en_bullets.json

.build/release/TurboFieldfareCLI --model scratch/gemma4-qat.gturbo \
  --messages-file <上の 4 本> --image <$TF_SAMPLE_IMGS の 1 枚> --image-tokens 280 \
  --seed <1234|1235|1236> --max-new 192 --max-context 4096 \
  --expert-cache-slots 32 --thinking off --draft-block-size 0 \
  --verification trusted-install --prefill on

python3 bench/mtp38_analyze.py     # 集計 (四則と標本 sd のみ)
```
