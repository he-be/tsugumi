## 2. 今どこにいるか

M9 は 34 が P1〜P7 を置き、35 (外部校正) → 36 (台帳) → 37 (並べ直し) →
**38 (register の検定) → 39 (48 スロット台帳)** と進んだ。
**`Sources/` は M9 を通じて 1 行も変えていない。**製品に入った変更はまだゼロで、

### 確定していること (**実測**、反復あり)

| | 中身 | 出典 |
| --- | --- | --- |
| 台帳の形 | `step(k) = base + Σc_i + d·k` は turbo でも成立。**内挿専用** (bs=6 以上で 10〜15% 破れる) | 36 §3b/§4d |
| `d` | **0.064 base/本**。画像 8 枚で ±3%、温度・thinking・スロット数で動かない | 36 §3b |
| `c(slots)` | 16/24/32/48 = **0.633 / 0.563 / 0.440 / 0.287**。**画像に依らない** (別画像で再現) | 39 §1 |
| 最適 bs | **2〜3。48 スロットでも 2 のまま伸びない** | 39 §2 |
| 既定 bs=4 | 動かす根拠なし。採点条件で差 +0.05% (95% 区間 ±2%) | 36 §17 |
| L1 の破れ | 壁時計 ≠ Σmax(io, busy)。正しくは **Σbusy + α(bs)·Σio** | 36 §14/§16 |
| α(bs) | bs=2 で 0.840 → bs=8 で 0.331。register にもスロット数にも依らない | 36 §16 |
| **`2^H` 軸** | `hit% = 108.67 − 0.6553·2^H` が **R² = 0.993**。`register` はこの連続量の代理ラベル | 38 §3 |
| 果実 A | **閉じない。**48 スロット MTP off の decode は 40.98 ms/tok で、**expert I/O は 21%** | 39 §4 |
| スロットの効き | 16→48 で I/O −38% でも壁時計は **−5.2%** (変換率 43%) | 39 §5 |

### 次の 1 手 — **N2**

`decode/tok` の残り約 25 ms/tok を **GPU busy と待ちに割る**。
39 §4 が「40.98 ms/tok の 8 割は expert I/O ではない」を出したので、
**その中身を開ける作業**であり、優先度は上がっている。

- 一次資料の大半は既に在る (37 §1a が既存ログ 9 run で 4 項を出した)
- 残りは **`TF_PREFILL_GPU_PROFILE` を有利/苦手の 2 register で 2 run**
  (`Sources/TurboFieldfare/Runtime/Prefill/PrefillGPUProfile.swift:57`)
- **ここで 34 の P2 (counters、1 日) に進むか捨てるかが決まる。**
  残りが GPU busy なら進む。待ちが主なら counters を取っても答えは出ない

その後は **N3 (採点基準 v2)**。ただし **37 の N3 から register 軸 (2×2) は落とすこと** —
38 §3 のとおり軸は `2^H` 1 本でよい。**N4/N5/N6 は 37 §3 のまま。**

## 4. 落とし穴 (実際に踏んだもの)

1. **n=1 のセルに解釈を書かない。**36 は 188 測定から 3,321 行を書き、
   看板の発見 (§11/§12) が n=1 だった。**反復 3 未満のセルは表に数字を置くだけにする。**
   38/39 はこの規則で書いて **115 / 116 行**に収まっている。
2. **`mtp_cd_sweep.py` の head/tail base は外れ値検出器である。**
   `|head/tail| > 5%` の run は捨てる (39 §3。実際に 1 本捕まえた)。
   36 §9g の 3 規則 (隣接ペア / 反復 3 以上 / 中央値・平均・分布を並べる) に続く 4 つ目。
3. **48 スロットは切り替え直後にページイン費用を払う** (6.78GB 常駐)。
   スイープの前に暖機を 1 本入れる (39 §3)。
4. **温度の既定 (temp 1.0 / top-k 64 / top-p 0.95) がそのまま運用点である。**
   `--temperature 0` を明示すると運用点から外れる。36 §11 はこれで n=1 のまま
   運用点でない条件を測っていた。
5. **macOS の `/bin/bash` は 3.2 で連想配列が無い** (`declare -A` が落ちる)。
6. **`sleep` を Bash ツールのコマンドに直接書くとタスクごと落ちる。**
   待つならスクリプト内に入れてバックグラウンドで投げる。
7. **生ログは必ずファイルにリダイレクトし、`bench/mtpNN/` にコピーしてコミットする**
   (`bench/logs/` は gitignore。`*.log` も gitignore なので `git add -f` が要る)。
