# サービング — 仕様先行体制

2026-08-19 に体制を変えた。**OpenAI 互換サーバーの仕様は参照実装
(`~/LLM/llama.cpp` の `tools/server`) と OpenAI API に既にある。**
ここで独自に設計・実験して仕様を作ることはもうしない。

| 文書 | 役割 |
| --- | --- |
| [SPEC.md](SPEC.md) | **唯一の規範仕様。**規範の優先順位、受理規則、エンドポイント、パラメータ表、キャッシュ (LCP)、思考、エラー、フラグ、逸脱登録簿。ID 付き |
| [CONFORMANCE.md](CONFORMANCE.md) | **TDD の進め方。**テスト階層 C0〜C3、既知の赤の一覧 (= 作業キュー)、実装順 P0〜P5、引き継ぐ/巻き直すの区分、完了の定義 |

進め方は 1 行で言える: **SPEC に行が無い挙動を書かない。赤いテストが無い行を
実装しない。クライアントの症状は SPEC 経由でしか実装に届かない。**

## 旧文書 (10〜16) について

S1〜S3 の実験ログ (10〜13) と棚卸し (14〜16) は削除した。実験ログを積んで
進める体制自体をやめたためで、内容は次のとおり回収済み:

- 乖離の棚卸しと実測 (14/16) → SPEC の各行と CONFORMANCE §2 の赤リスト。
- LCP 移行設計 (15) → SPEC §7 と CONFORMANCE §3 の P1 (D1〜D5 の順序ごと)。
- S1〜S3 の到達点 → SPEC の「実装済」行 (MSG-6, RSN-5, RSP-1/2/4 など)。

原本: 10〜13 は git 履歴 (`git log --diff-filter=D -- docs/serving`)。
14〜16 は未コミットだったため削除前のセッションの scratchpad に退避してある
(揮発。必要な内容は上記に吸収済み)。
