# 07. 設計を決める実験 — 前提を先に固定し、模擬の壁時計で A / B を決める

**前提 (2026-09-25 ユーザー、[12 §1](12-Q1-REDESIGN.md) の P1〜P5):** M6 の GPU 経路は fp16 の tensor ops (P1)、M6 の担当分は常駐させてよい (P2)、
物差しは本文 2 の壁時計で閾値は Q0 の揺れ幅 × 2 (P3)、Q2 を先に済ませてから比べる (P4)、式は格子を絞るだけで判定は模擬の実測 (P5)。**前提を動かすなら全部測り直す。**

2 機の分け方は 2 つある ([08](08-CANDIDATES.md): **A** 層で分ける / **B** expert で分ける)。**推論で選ばない。式でも選ばない。**
E0〜E2 (済み、数字は [10 §1](10-Q1-SPLIT-DECISION.md)) は式に入れる量、F0〜F4 ([12 §2](12-Q1-REDESIGN.md)) は判定に使う実測。

証拠は `bench/qfn/results/YYYY-MM-DD-<Mac15-6|Mac18-5|pair>-<e|f><N>/`、規則は [02](02-EVIDENCE.md)。**n ≥ 3、同じ入力、run ごとに「まだ読んでいない層」か新しいプロセス。**

## 決め方 ([12 §3](12-Q1-REDESIGN.md)。計測の前に置く。後から動かさない)

1. F2・F3 の壁時計に記録のラウンド分布 (1 チャンク 55 本、2 チャンク 10 本、3 チャンク 3 本) を掛けて 1 ターンの prefill 合計秒を A と B で出す。
2. 小さい方を作る。差が F0 の閾値未満なら **B**。
3. 常駐は F4 の上限の中で使う。冷えた条件でしか速くならない分け方は選ばない。
4. 模擬と式のずれは結果文書に書く。式は直さない。

決めた結果は結果文書 (10 番台) に、証拠のリンク付きで書く。README の Gate の表はそこで更新する。
