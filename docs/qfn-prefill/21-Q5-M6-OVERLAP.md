
`QFN_SLAB=<n>` (M6、A だけ、既定 1) は staging を n 個にする。非常駐層は並び順で置き場を順に使い、読み手のスレッドが (チャンク, 層) の順に先へ読む (送りの受信を含む)。
層は自分の読みを待ってから GPU を回し、GPU が終わると置き場を返す。待った秒を `slab_wait_s` 列に出す。1 は 20 までと同じ直列。

反復 n = 3。全 6 本が両機 exit 0、`guarded.sh` の Swapouts 増分は両機とも全部 0。

**台帳** ([06](06-LEDGER.md)): 模擬の道具 (`QFN_SLAB`、既定 1) だけで、ランタイムは変えていない。台帳 §1 は動かない。

## 0. 結論

1. **M6 のチャンクは 6.301 → 3.829 s (チャンク 0)、6.252 → 3.767 s (チャンク 1)、差 2.472 / 2.485 s。**04 Q5 の閾値 (M6 のチャンクで 3.06 s) に 0.6 s 届かない。
   04 Q5 の規則 (1 つでも外れたら既定に入れず候補) により **`QFN_SLAB=2` は候補のまま**。
   t1 6.321 → 3.860 s、t2 12.578 → 7.612 s、記録の 1 ターン (20 と同じ配分、導出) 529.9 → 322.5 s。
2. **RAM は入った。**staging 2 × 0.73 GB、常駐 13 層 (10.54 GB) のまま Swapouts 0。run の終わりの M6 の wired 14.32〜14.34 GB (1 層分は 13.59〜13.61 GB)、free 0.76〜0.84 GB。
   wired は `recommendedMaxWorkingSetSize` の 14336 MiB (15.03 GB) の下。常駐 12 層の比較は要らなかった。
3. **見込み (約 3.4 s、20 §3) から 1 割以上ずれた (3.83 s)。ずれたのは読みの方。**非常駐層は 1 層ごとに読み (平均 0.084 s) が計算 (0.068 s) より長い。
   常駐 13 層の計算 (0.87 s) の裏では置き場 2 つ分 (層 13・14) しか先に読めない。見込みはチャンク全体の読みの和 2.93 s と計算の和 3.28 s の max で、層ごとの釣り合いと置き場の数を見ていなかった。

## 2. 分かったこと / 外れたこと

- 04 Q5 の合否: **Swapouts 0 (両機)、wired ≤ `recommendedMaxWorkingSetSize` は通った。M6 のチャンクの差 2.47〜2.49 s は閾値 3.06 s に届かない。**t1 の差 2.461 s も届かず、t2 の差 4.966 s は超える。
  04 の規則どおり既定に入れず候補とする。
- 03 の表の M6 の `recommendedMaxWorkingSetSize` 12,124 MiB (m6-prefill/03 から、wired limit の記載なし) に対し、wired limit 14336 のもとでは 14336 MiB (rmw.m6.txt)。
- 残りの 0.5〜0.6 s は非常駐層の読みの待ちで、置き場を増やしても層 15〜47 の読みが律速のまま (1 層ごとに読み > 計算)。
  常駐層 13 個が先頭に並んでいるので、その計算 0.87 s の裏で使えるのは置き場の数の層分だけ。常駐を層 0〜12 のまとまりでなく非常駐層の間に散らせば、読みの裏になる計算が増える (導出、未測定)。
  置き場を 3 つ以上にするのは free 0.76〜0.84 GB に 0.73 GB を足すことになる。

## 3. 次の Gate に渡すもの

- `QFN_SLAB=2` は候補 (04 Q5 の閾値に届かず)。Q6 の k の格子は 1 層分を既定として取り、2 層分は候補の列として並べられる。
- 分母: k 48・送り 0.59 の M6 のチャンクは、1 層分で 6.30 / 6.25 s、2 層分で 3.83 / 3.77 s。1 ターン (導出) は 529.9 / 322.5 s。
- 開いたまま: 常駐層を非常駐層の間に散らす並べ方 (§2)、run 中の wired の最大、置き場 2 つのときの送りの比 (0.59 は直列のときの帯域比で決めた)。
- 03 の `recommendedMaxWorkingSetSize` の M6 の行に、wired limit 14336 のときの値 (14336 MiB、この文書) を併記した。
