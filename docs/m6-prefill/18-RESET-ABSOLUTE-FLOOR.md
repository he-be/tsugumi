# 18. 方向の取り直し — 進捗は既定のバイナリの秒だけで測る (2026-09-24)

**新しい実測は無い。**この文書は、10〜17 の進め方のどこが間違っていたかと、以降の規則を書く。数字は既存の証拠からの引用と導出だけ。
以降の計画は [04](04-GATES.md) に書き直し、台帳を [06](06-LEDGER.md) に置いた。[17 §3](17-NAX-NOT-USED.md) の方針 (tensor ops 化を順に進める) はこの文書で取り消す。

この文書の最初の版は「下限の何倍か」で進めると書いた。同じ日に取り消した (§0 の 4)。

## 0. 何が間違っていたか

1. **分母が G0 だった。**04 は「以降の N 倍の分母は G0 の壁時計と routed MoE の秒数」と決めていた。
   そのため、10 倍以上遅い段があっても「G0 より縮んだか」しか問わなかった。**絶対値として妥当かを一度も確かめていない。**
2. **手段が目的になっていた。**G1〜G4 は「tensor ops (`matmul2d`) に載せる」ことを Gate にした。
   手を入れる段を「tensor ops に載るかどうか」で選んだ。その段が下限からどれだけ遠いかでは選ばなかった。
   その結果、天井の 1/4〜1/2 で動いていた大きな GEMM だけを縮めた ([12](12-G3-MOE-MATMUL2D.md)、[13](13-PROJ-SHARED-MATMUL2D.md))。10〜40 倍遅い段 (§1) には触れなかった。
3. **測っている量の定義が混ざっていた。**`prefill_bench.sh` は毎回新しいプロセスで 1 回だけ prefill する。そのため prefill の壁時計に次の 2 つが入る。
   - **起動時の完全性検証。**最初に触った層ファイルの SHA-256 で、モデルの expert 12.9 GB 全体、CPU で約 4.5 s ([10 §1.1](10-G0-BASELINE.md) の layerVerify)。
   - **空の expert キャッシュ。**hit 0%。

   [14](14-G5-VERIFY-AHEAD.md) の「6.98 → 4.43 s」の大部分は、prefill を速くしたのではない。この起動時のハッシュを GPU の裏に隠しただけである。
4. **既定の経路を一度も測り直していない。**`env.txt` に `TF_` が 1 行も無い証拠ディレクトリは G0 の基準線 (837586c、9.506 s) だけ。
   10〜14 の変更はすべて環境変数で開く候補で、既定にしたものは無い。それなのに結果文書の題は「9.01 → 7.38 s」「6.98 → 4.43 s」「1.58 倍」と、候補同士の比を進捗の形で書いた。
   ユーザーが既定のバイナリで得る数字は基準線から動いていない。
   この文書の最初の版が置いた「下限の何倍か」も同じ穴である。下限は導出で、分母を選べる数はどれも盛れる。**分母の無い秒だけを進捗にする** ([06](06-LEDGER.md))。

## 1. 絶対値で見て外れている段 (既存の証拠から)

演算量は [17 §1](17-NAX-NOT-USED.md) の導出。2478 トークンの prefill 全体で約 16.7 TFLOP。
MPS の fp16 GEMM は M6 で 18.61 TFLOP/s ([03 §1](03-FACTS.md))。**GPU 側の天井は 1 秒前後 (導出)**。
今の最良構成で、GPU 合計は約 4.7 s、壁時計は 4.4 s ([14](14-G5-VERIFY-AHEAD.md)) である。

段ごとの秒は [`a0-profile-detail`](../../bench/m6/results/2026-09-24-Mac18-5-a0-profile-detail/summary.tsv) の level 2 (n = 3)。level 2 は膨らむので桁だけを読む。

| 段 | 実測 | 仕事の量 (導出) | 読み |
| --- | ---: | --- | --- |
| `post` (post norm + router) | 0.415 s | router は 1 層あたり 2478 × 2816 × 128 の積和、全層で約 0.05 TFLOP | 演算量では説明できない。router の重みをトークンの数だけ読み直す作り (下記) |
| `rope` (RoPE + Q/K norm) | 0.191 s (G0 では 0.446 s) | 要素ごとの処理。Q と K で 1 層あたり約 1500 万要素 | 帯域の下限は数十 ms 以下の桁 (**下限表 B1 で確定させる**) |
| `attn.swa` (sliding window の attention 本体) | 1.433 s | 0.82 TFLOP ([17 §1](17-NAX-NOT-USED.md)) | 実効 0.6 TFLOP/s。天井の 1/30 |
| `attn.full` | 0.299 s | 0.50 TFLOP | 実効 1.7 TFLOP/s |
| routed MoE / shared / 射影 | 1.08 / 0.57 / 0.62 s | 7.07 / 2.65 / 5.57 TFLOP | 実効 4.6〜9 TFLOP/s。今日縮めたのはここだけ |

- **router はトークンごとの GEMV である。**ベンチのモデルの router は bf16 (manifest の `quant.router.weightBits` = 16) なので、`prefill.metal` の `prefill_router_gemma4_bf16_block` を使う。
  このカーネルは 1 トークンに 1 threadgroup を割り当てる。各スレッドは 1 expert 分の 2816 次元の内積を、bf16 のスカラー読みで回す。router の重み (128 × 2816 × 2 バイト = 0.72 MB) は、トークンの数だけ読み直している。
  `PrefillPostAttentionSetup` と `PrefillLayerTail` も、1 トークンに 1 threadgroup の形で dispatch している。
- **ホストとの往復が層ごとに入る。**30 層 × 2 チャンクのたびに、GPU を待ち (`wait.front` 2.9 s、[14 §1.1](14-G5-VERIFY-AHEAD.md) の run 群)、routing を CPU に読み戻して並べ替える。

上の「読み」の列の下限は概算である。**正式な下限は B1 ([04](04-GATES.md)) で段ごとに出し直す。**

## 2. 以降の規則

1. **進捗は台帳 ([06](06-LEDGER.md)) の既定行の秒だけ。**既定のバイナリ (`TF_` なし、追加引数なし)、`prefill_bench.sh` の固定コマンド、新しいプロセスの 1 回目の prefill 壁時計。
   行は `bench/m6/ledger.sh` が証拠ディレクトリから生成する。手で書かない。比の列は無い。
2. **倍率・%・pp・「下限の何倍か」を進捗として書かない。**結果文書の題にも本文にも書かない。変更の効果は「変更前 X s、変更後 Y s、差 Z s」。
3. **`TF_` 付きの構成は候補。**候補の秒は台帳 §2 と結果文書に残るが、進捗ではない。既定に入れる判断はユーザー ([04 B3](04-GATES.md))。既定に入れたら `ledger-*` を取り直して §1 の行で示す。
4. **段ごとの下限表 ([04 B1](04-GATES.md)) は、手を入れる段を選ぶ道具。**(実測 − 下限) の秒が大きい順に選ぶ。倍率の列は作らない。手段 (tensor ops、融合、タイル化、ホスト往復の削減) は、段を選んだ後に決める。
5. **測る量を分ける。**(a) 起動と初回の完全性検証、(b) 同じプロセスでの 2 回目以降の prefill、(c) 新しいプロセスでの 1 回目の prefill。台帳の量は (c)。
   (b) を測る口 (同じプロセスで同じプロンプトを繰り返す) は無い。CLI の変更が要るので判断待ち ([04 B0](04-GATES.md))。口ができたら台帳に (b) の列を足す。
6. **結果文書は冒頭に「既定か候補か」と、対応する台帳の行を書く。**候補なら「台帳 §1 は動かない」と明記する。

## 3. 10〜17 の扱い

- **実測の数字はどれも有効**である。証拠ディレクトリはそのまま残す。
- **解釈は読み替える。**
  - [12](12-G3-MOE-MATMUL2D.md)、[13](13-PROJ-SHARED-MATMUL2D.md) の壁時計は、どれも (c) で測っている。起動時のハッシュを含む。
  - [14](14-G5-VERIFY-AHEAD.md) の縮みは、(c) の中で起動時のハッシュを隠したものである。(b) の prefill の改善ではない。

- **12・13・14 の題と本文にある倍率 (「2.35 倍」「1.58 倍」) は読まない。**秒だけを読む。文書は書き換えず、この読み替えを 04 の索引に置いた。
