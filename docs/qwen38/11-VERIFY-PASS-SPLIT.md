# 11. 投機の検証 (T=2) は素の decode (T=1) より何に時間を使っているか

実測: 2026-09-14、M3 Pro 18 GB、macOS 15。対象は [10](10-MTP-SHADOW-SPEC.md) と同じ GGUF・ランナー・プロンプト。
表記は 01 と同じ (実測 / 導出 / 未確認)。**どのセルも 2 パス (または 1 パス) なので、数字だけを書く。**
ここで扱うのは decode だけで、prefill の時間は含めない。

## 0. 結論

1. **検証 (T=2) が素 (T=1) より長い約 40 ms は、ほぼ expert の I/O である** (§2)。advise のシステムコールが +12〜16 ms、
   routed のバッファが GPU を始めるまでの待ち (kernel→GPU 開始) が +18〜24 ms。GPU は +4〜5 ms、pre と head は増えない。
   選ばれる expert は 480 → 774〜837、ページキャッシュに無いバイトは 1 ステップ 156〜189 → 322〜432 MB (§1)。
2. **pread (T ≥ 1) に替えると素も投機も遅い** (§3)。投機の steady は 8.44〜8.73 → 6.93〜6.95 tok/s。
   pread の後でも kernel→GPU 開始は T=1 で 12〜13 ms、T=2 で 18〜19 ms 残る (SSD でない常駐の費用)。
3. **advise を並列・非同期に出す腕は、腕の差が反復の差に埋もれた** (§4)。取り分の上限が advise の 15〜31 ms で、
   それも読み終わりの待ちに移るだけなので、途中で止めた。コードは消した。
4. **routing が正確なら、層 L の読みは隠せない** (§5)。n_max を上げても鎖は同じで、和集合の分だけ読むバイトが増える。
   隠すには層 L の hidden より前に層 L の expert を当てる予測が要り、Qwen3.8 での的中率は未測定。

## 4. advise を並列・非同期に出す腕 (途中で停止)

`Q38_ADVISE_MODE=inline|parallel|async` (parallel は `readThreads` 本に分けて待つ、async は待たずに commit) を code で 2 パスまで (12 本中 10 本):

| 腕 | inline | parallel | async |
| --- | --- | --- | --- |
| 素 steady 中央値 ms | 160 / — | 151 / 142 | 147 / 161 |
| 投機 steady tok/s | 8.72 / 8.20 | 8.43 / 8.09 | 7.91 / 8.02 |

同じ腕の 2 パスの差 (async の素 147 / 161) と腕の差が同じ大きさ。取り分の上限が advise の 15〜31 ms で、読み終わりの待ちは残るので止めた。
切り替えのコードは消した (`scratch/qwen38/advise11/` のログだけ残る)。

## 5. 順序の制約 (導出、測っていない)

T=1 の 1 トークンの中で、層 L の expert id は層 L の注意/GDN・hc_ffn・router を通った hidden で決まり、それは層 L-1 の routed の出力を要る:

```
routed(L-1) [読み待ち] → pre(L) → id(L) → 読み(L) → routed(L) → pre(L+1) → …
```

- 読み(L) と重ねられる正確な計算は、層 L の shared expert とキャッシュ済みの expert の分だけ。層 L+1 は全部 routed(L) を待つ。
  Gemma の経路 (`docs/SYSTEM_DESIGN.md` の cb1 / io / cb2) が重ねていたのもこの範囲。`Qwen38Runner` は層ごとに 2 回同期で待ち、shared expert も id の前のバッファにある。
- 検証 (T = n_max + 1) でも同じ鎖で、行が増えると和集合 (480 → 774〜837) と読むバイトが増える。MTP のドラフトが先に与えるのは次のトークンだけで、幹の層の expert ではない。
- 鎖の外に読みを出すには、層 L の hidden より前に層 L の expert を当てる予測が要る。Gemma では層 L の router 入力に層 L+1 の重みを当てて
  ミスの 66% (上位 1 本で 70%) を当てたが、壁時計は −1.5〜−3.5% だった ([mtp/29](../mtp/29-M8-B-PROBE.md)、[mtp/30](../mtp/30-M8-B-PREFETCH.md))。Qwen3.8 での的中率は未測定。
